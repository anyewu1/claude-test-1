# Vue3 平时学习笔记

> 本笔记记录本学期 Vue3 学习过程中的核心知识点、心得与项目实践。

## 第一章 - Vue3 简介与环境搭建

### 1.1 什么是 Vue3

Vue3 是 Vue.js 的最新主版本,于 2020 年 9 月发布。相比 Vue2,Vue3 在性能、TypeScript 支持、组合式 API 等方面有重大升级。

### 1.2 引入方式

#### 方式一: CDN (本项目使用)
```html
<script src="https://unpkg.com/vue@3/dist/vue.global.prod.js"></script>
```
优点: 零配置,适合学习和小项目

#### 方式二: 脚手架
```bash
npm create vue@latest
```
优点: 工程化,适合大型项目

### 1.3 创建第一个 Vue3 应用

```javascript
const { createApp, ref } = Vue;
createApp({
  setup() {
    const msg = ref('Hello Vue3!');
    return { msg };
  }
}).mount('#app');
```

## 第二章 - 响应式系统

### 2.1 ref vs reactive

#### ref - 适合基本类型
```javascript
const count = ref(0);
count.value++;  // 在 JS 中需要 .value
// 模板中自动解包: {{ count }}
```

#### reactive - 适合对象
```javascript
const user = reactive({ name: '张三', age: 20 });
user.name = '李四';  // 直接修改,无需 .value
```

#### 何时用哪个?
- **ref**: 基本类型 (number, string, boolean)、单个值
- **reactive**: 对象、数组、复杂结构

### 2.2 computed - 计算属性

```javascript
const firstName = ref('San');
const lastName = ref('Zhang');
const fullName = computed(() => lastName.value + firstName.value);
```

**特点**:
- 基于依赖缓存,依赖未变不会重新计算
- 适合派生数据

**本项目应用**:
```javascript
const canLogin = computed(() => 
  agreed.value && account.value && password.value
);
```
当账号、密码、协议任一变化时,自动更新按钮状态。

### 2.3 watch - 侦听器

```javascript
watch(count, (newVal, oldVal) => {
  console.log(`从 ${oldVal} 变为 ${newVal}`);
});
```

## 第三章 - 模板语法

### 3.1 文本插值

```html
<span>{{ message }}</span>
<span>{{ count + 1 }}</span>
<span>{{ ok ? '是' : '否' }}</span>
```

### 3.2 指令

| 指令 | 作用 | 示例 |
|------|------|------|
| `v-bind` (`:`) | 属性绑定 | `:class="active"` |
| `v-on` (`@`) | 事件绑定 | `@click="onClick"` |
| `v-model` | 双向绑定 | `<input v-model="text">` |
| `v-if` / `v-else` | 条件渲染 | `<div v-if="show">` |
| `v-for` | 列表渲染 | `<li v-for="item in list">` |
| `v-show` | 显示/隐藏 | `v-show="visible"` |

### 3.3 v-model 在本项目的应用

```html
<input class="form-input" v-model="account" placeholder="请输入手机号或邮箱">
```

- 输入框值与 `account` 自动双向同步
- 比手动监听 `input` 事件并 `setValue` 更优雅

### 3.4 动态 class 绑定

```html
<button :class="{ active: canLogin }">登录</button>
```

`canLogin` 为 true 时添加 `active` 类,实现按钮激活态切换。

## 第四章 - 组合式 API (Composition API)

### 4.1 setup() 函数

```javascript
setup() {
  const count = ref(0);
  const increment = () => count.value++;
  return { count, increment };
}
```

`setup` 返回的对象会暴露给模板使用。

### 4.2 选项式 API vs 组合式 API

#### 选项式 (Options API) - Vue2 风格
```javascript
export default {
  data() { return { count: 0 }; },
  methods: { increment() { this.count++; } }
}
```

#### 组合式 (Composition API) - Vue3 推荐
```javascript
setup() {
  const count = ref(0);
  const increment = () => count.value++;
  return { count, increment };
}
```

**组合式优势**:
- 逻辑组合,相关代码聚集在一起
- TypeScript 支持更好
- 适合大型组件

### 4.3 生命周期钩子

| Vue2 | Vue3 (组合式) | 触发时机 |
|------|--------------|----------|
| beforeCreate / created | setup() | 组件创建时 |
| beforeMount | onBeforeMount | 挂载前 |
| mounted | onMounted | 挂载后 |
| beforeUpdate | onBeforeUpdate | 更新前 |
| updated | onUpdated | 更新后 |
| beforeDestroy | onBeforeUnmount | 卸载前 |
| destroyed | onUnmounted | 卸载后 |

## 第五章 - Vue3 与 Vue2 主要区别

| 维度 | Vue2 | Vue3 |
|------|------|------|
| 响应式实现 | Object.defineProperty | Proxy |
| 数组监听 | 重写 7 个方法 | 原生支持 |
| 多根节点 | 不支持 | 支持 Fragment |
| 组合式 API | 无 | 有 setup |
| TypeScript | 一般 | 一流支持 |
| Tree-shaking | 不友好 | 友好,体积更小 |
| 性能 | 基线 | 渲染快 1.3-2 倍 |

## 第六章 - 项目实践心得

### 6.1 本项目用到的核心 API

```javascript
const { createApp, ref, computed } = Vue;
createApp({
  setup() {
    // 响应式数据
    const account = ref('');
    const password = ref('');
    const agreed = ref(false);
    
    // 计算属性
    const canLogin = computed(() => 
      agreed.value && account.value && password.value
    );
    
    // 事件处理
    const onLogin = () => { /* ... */ };
    
    return { account, password, agreed, canLogin, onLogin };
  }
}).mount('#app');
```

### 6.2 学习收获

1. **响应式数据极大简化了表单处理**: 比 jQuery 或原生 DOM 操作清晰太多
2. **组合式 API 让逻辑组织更灵活**: 相关代码可以放在一起,不再分散在 data/methods/computed
3. **CDN 引入降低了学习门槛**: 不必先学 Node.js、Webpack 就能上手
4. **`.value` 习惯需要适应**: ref 在 JS 中需要 `.value`,模板中自动解包

### 6.3 遇到的坑

#### 坑 1: ref 忘记 .value
```javascript
const count = ref(0);
console.log(count);        // ❌ 输出 RefImpl 对象
console.log(count.value);  // ✅ 输出 0
```

#### 坑 2: setup 中的 this
组合式 API 中 `this` 不指向组件实例,所有状态需通过参数或闭包获取。

#### 坑 3: 解构会失去响应性
```javascript
const state = reactive({ count: 0 });
const { count } = state;  // ❌ count 失去响应性
const { count } = toRefs(state);  // ✅ 使用 toRefs
```
