# 设计视频录制说明

## 一、说明

由于本项目部分开发环境为云端容器,无法直接录制屏幕视频,因此本文档提供详细录屏脚本,便于在本地环境录制提交。

## 二、推荐录屏工具

| 系统 | 推荐工具 | 是否免费 |
|------|---------|---------|
| Windows | OBS Studio / 屏幕录制工具 (Win+G) | 免费 |
| macOS | QuickTime Player / OBS Studio | 免费 (自带) |
| 在线 | Loom / Screen Recorder Online | 部分免费 |
| 手机模拟 | Chrome DevTools 设备模拟 + 桌面录屏 | 免费 |

## 三、视频时长建议

- 总时长: **1 分 30 秒 — 2 分钟**
- 分辨率: 1080p / 720p 均可
- 帧率: 30 FPS

## 四、录屏脚本 (Step-by-Step)

### 开场 (0:00 - 0:10)
**画面**: 项目目录或 README 文件
**配音 (建议字幕)**:
> "大家好,这是我的 Web 前端期末作品 —— 粉色登录页 APP 设计,基于 HTML5 + Vue3 实现。"

### 项目结构展示 (0:10 - 0:25)
**画面**: 文件管理器中展示 task1-mobile-app 目录
**演示动作**:
- 展开 `task1-mobile-app/` 目录
- 依次展示 `index.html`, `README.md`, `docs/`, `assets/icons/` 子目录

### 启动项目 (0:25 - 0:35)
**画面**: 双击 index.html 在浏览器打开
**配音**:
> "项目无需构建,双击 index.html 即可运行,真正做到零配置部署。"

### 页面展示 (0:35 - 1:00)
**画面**: 浏览器中完整页面
**演示动作**:
- 从上至下展示页面:
  - 状态栏 (14:57, 网络图标, 电量)
  - 导航栏 (返回箭头, "账号密码登录"标题)
  - 账号输入框
  - 密码输入框 + "忘记密码"
  - 登录按钮 (浅粉色未激活状态)
  - "手机短信登录"
  - 底部协议
  - "登录遇到问题"

### 输入与交互 (1:00 - 1:30)
**演示动作**:
1. 点击账号框,输入 `13800138000` (展示 v-model 数据绑定)
2. 点击密码框,输入 `123456` (密码被遮蔽)
3. 点击"忘记密码" - 弹出提示框,关闭
4. 不勾选协议直接点登录 - 弹出"请先阅读并同意协议"
5. 勾选协议 checkbox - **重点展示按钮颜色变化** (浅粉 → 渐变粉)
6. 点击"登录" - 弹出"登录成功!欢迎使用~"

### 收尾 (1:30 - 2:00)
**画面**: 切回代码或文档
**配音**:
> "本项目使用 Vue3 Composition API 实现响应式数据绑定,代码精简、扩展性强。完整学习笔记请见 docs/平时笔记.md。谢谢观看!"

## 五、录制小贴士

1. **录制前关闭通知**: 避免微信、QQ 弹窗影响视频
2. **使用主题简洁的桌面**: 减少干扰
3. **鼠标放大**: 录屏软件开启鼠标高亮,便于观看者跟随
4. **配音**: 可以使用文本转语音或后期添加字幕,清晰即可
5. **导出格式**: MP4 / MOV,大小建议 < 100MB

## 六、提交格式

录制完成后,将视频文件命名为:
```
作品演示_姓名_学号.mp4
```

放入项目压缩包中一同提交。

## 七、移动端模拟录制 (进阶推荐)

为更真实地展示移动 APP 效果,推荐使用 Chrome DevTools:

1. 在 Chrome 中打开 `index.html`
2. 按 `F12` 打开开发者工具
3. 点击左上角 "Toggle device toolbar" (Ctrl+Shift+M)
4. 选择 "iPhone 12 Pro" 或类似机型
5. 此时页面以移动端模式显示
6. 开启桌面录屏,捕捉浏览器窗口区域即可

这样录出的视频更具备"真实 APP 在手机上运行"的视觉效果。
