# 设计过程说明

## 一、项目背景

本项目是 Web 前端开发课程的期末作品,要求以本学期所学 HTML 开发技巧,模仿正规 APP 页面的设计效果。结合移动互联网时代用户对登录体验的高要求,本项目选取了清新粉色风格的移动端登录页作为设计对象。

## 二、设计灵感

设计灵感来源于当下流行的"少女风""治愈系" APP (如小红书、微博、网易云音乐青春版等)。粉色调具备以下优势:

- **情感价值**: 粉色给人柔和、温暖、亲切的视觉感受
- **目标用户**: 年轻女性用户群体偏好度高
- **品牌识别**: 区别于普通蓝色调登录页,具备记忆点
- **视觉舒适**: 浅粉与白色搭配,长时间停留不疲劳

## 三、配色方案

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主粉色 | `#FFB6C1` / `#FFC1D1` | 登录按钮默认背景 |
| 激活粉 | `#FF8AA6` | 登录按钮激活、忘记密码、checkbox 选中 |
| 渐变粉 | `linear-gradient(90deg, #ff8aa6, #ffa5bd)` | 按钮激活渐变 |
| 主文字 | `#333` | 标题、表单标签 |
| 占位符 | `#C8C8C8` | 输入框 placeholder |
| 描述灰 | `#888` / `#B5B5B5` | 协议文字、辅助链接 |
| 协议链接 | `#3F8FD3` | "用户协议""隐私政策"链接色 |
| 背景白 | `#FFFFFF` | 整体背景,简洁干净 |

## 四、信息架构与布局

页面自上而下分为五个核心区域:

1. **状态栏** (Status Bar)
   - 显示时间 `14:57`、NFC、蓝牙、WiFi、4G、电量 `74%`
   - 模拟真实手机顶部信息栏

2. **导航栏** (Nav Bar)
   - 左侧返回箭头 `<` (SVG 绘制)
   - 居中标题"账号密码登录"
   - 高度 48px,符合移动端设计规范

3. **表单区** (Form)
   - "账号"标签 + 占位符"请输入手机号或邮箱"
   - "密码"标签 + 占位符"请输入密码" + 右侧粉色"忘记密码"链接
   - 底部细线分隔,极简风格

4. **登录按钮** (Login Button)
   - 大圆角矩形 (border-radius: 25px)
   - 未勾选协议时使用浅粉色 `#FFC1D1` (半激活状态)
   - 勾选后切换为渐变粉色 (完全激活)

5. **底部协议区** (Footer)
   - 圆形 checkbox + 协议同意文案
   - "用户协议""隐私政策"使用蓝色链接突出
   - 底部"登录遇到问题"辅助链接

## 五、交互设计要点

### 5.1 输入校验
- 点击登录按钮时校验账号与密码不为空
- 未勾选协议时阻止登录并弹出提示

### 5.2 协议勾选
- 默认未勾选,登录按钮显示为浅色半激活态
- 勾选后按钮立即变为渐变粉色,视觉提示用户"可以登录了"
- checkbox 使用 CSS 伪元素绘制对勾,避免引入图片

### 5.3 触摸反馈
- 所有可点击元素 `cursor: pointer`
- 移除点击高亮 `-webkit-tap-highlight-color: transparent`

## 六、技术选型理由

### 6.1 为什么选择 Vue3 (CDN)?

| 方案 | 优点 | 缺点 |
|------|------|------|
| 原生 JS | 无依赖 | 数据绑定繁琐 |
| **Vue3 CDN** | **响应式数据绑定优雅、零构建、单文件可运行** | **依赖网络** |
| Vue3 + Vite | 工程化最佳 | 需 Node.js 构建 |

最终选择 **Vue3 CDN**:
- 满足"可运行的 HTML 源代码"要求 (双击即开)
- 用 `ref` + `v-model` 简化表单逻辑
- 用 `computed` 计算按钮激活状态
- 满足课程"VUE3 有加分"要求

### 6.2 为什么内联样式?

将 CSS 写在 `<style>` 标签内而非外部文件:
- 单文件交付,无 CSS 文件丢失风险
- 控制总代码量 (符合"尽量少的代码"要求)
- 学习者一文件即可看完整设计

## 七、开发过程

### Step 1 - 静态结构
先用纯 HTML + CSS 实现静态页面,完全还原参考图

### Step 2 - 引入 Vue3
通过 `<script src="https://unpkg.com/vue@3">` 引入

### Step 3 - 数据绑定
- `v-model` 绑定账号/密码输入
- `:class` 动态切换按钮激活态
- `@click` 绑定按钮事件

### Step 4 - 校验逻辑
使用 `computed` 计算 `canLogin`,联动账号、密码、协议三项

### Step 5 - 视觉打磨
微调间距、字号、颜色,确保与参考图视觉一致

## 八、遇到的问题与解决

1. **问题**: 圆形 checkbox 内的对勾如何不用图片实现?
   **解决**: 使用 CSS `::after` 伪元素 + `border-left` + `border-bottom` + `transform: rotate(-45deg)` 绘制

2. **问题**: 状态栏的多个图标如何处理?
   **解决**: 全部使用内联 SVG,无需引入图标库,体积极小

3. **问题**: 移动端点击高亮影响美观?
   **解决**: 全局设置 `-webkit-tap-highlight-color: transparent`

4. **问题**: 在桌面浏览器查看时如何模拟手机窗口?
   **解决**: 限制 `#app` 最大宽度 414px (iPhone Pro Max 宽度),居中显示

## 九、设计总结

本设计追求"少即是多",代码量精简、视觉清新、交互流畅。粉色主调营造温柔氛围,Vue3 响应式让交互逻辑清晰可维护,整体既符合作业要求又具备实际可用性。
