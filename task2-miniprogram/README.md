# 校园助手 (Campus Helper)

> 大学生一站式学习生活助手 - 微信小程序

## 项目简介

校园助手是一款面向大学生的微信小程序,集成课程表、成绩查询、图书借阅、签到打卡、通知公告等校园生活常用功能于一体,旨在帮助同学们高效管理校园学习生活。

## 功能特性

### 📚 学习管理
- **课程表**: 周课表网格展示,支持点击查看课程详情
- **成绩查询**: 按学期筛选成绩,自动计算 GPA、平均分、总学分
- **图书馆**: 借阅记录管理,支持搜索、续借、归还

### 📅 校园生活
- **日程**: 月历视图展示重要日期,标记考试、活动
- **签到**: 每日签到打卡,连续签到奖励
- **通知**: 校园通知公告,支持重要/活动/普通分类

### 👤 个人中心
- 学生信息卡片
- 数据概览统计
- 设置中心 (主题、字号、通知)

## 技术栈

- **框架**: 原生微信小程序框架
- **语言**: JavaScript (ES6+) + WXML + WXSS
- **数据存储**: `wx.storage` 本地存储
- **样式单位**: `rpx` 自适应单位
- **基础库版本**: 2.30.4+

## 快速开始

### 1. 准备环境
- 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 准备微信小程序 AppID (可使用测试号)

### 2. 导入项目
1. 打开微信开发者工具
2. 选择 "导入项目"
3. 项目目录选择本 `task2-miniprogram` 文件夹
4. AppID 填入您的 AppID,或选择 "测试号"
5. 点击 "导入" 完成

### 3. 编译运行
- 点击 "编译" 按钮即可在模拟器中运行
- 点击 "预览" 生成二维码,用微信扫描可真机调试

详细部署步骤请参考 [部署说明.md](./部署说明.md)。

## 数据说明

首次启动小程序会自动注入示例数据,包含:
- 15 门课程 (周一到周五课表)
- 12 门成绩 (两个学期)
- 6 本图书 (借阅记录)
- 6 条通知公告
- 5 项日程事件
- 5 项待办任务
- 7 天历史签到记录

所有数据存储在本地 `wx.storage`,可在"设置 → 重置数据"中恢复初始状态。
