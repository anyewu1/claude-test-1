# 校园助手 - 使用说明

> 本文档介绍校园助手小程序各功能模块的详细使用方法。

## 一、首次启动

首次启动时,小程序会自动注入示例数据,包括课程表、成绩、图书、通知等。所有数据存储在本地,后续操作均基于这些初始数据。

模拟学生身份:
- 姓名: 李同学
- 学号: 20230101001
- 班级: 计算机科学 2301
- 学院: 信息工程学院

## 二、底部 tabBar 导航

底部导航栏包含 4 个 Tab,可快速切换:

| 图标 | 名称 | 功能 |
|------|------|------|
| 🏠 | 首页 | 数据概览,快捷入口 |
| 📅 | 课表 | 周课表展示 |
| 🔔 | 通知 | 校园通知公告 |
| 👤 | 我的 | 个人中心 |

## 三、各页面使用说明

### 1. 首页 (Home)

**位置**: 底部 tab "首页"

**功能模块**:
- **欢迎卡片**: 显示当前日期、星期、教学周次
- **数据统计**: 今日课程、待办、未读通知、借阅图书数量
- **快捷入口**: 4 个图标快速访问成绩、图书馆、日程、签到
- **今日课程**: 自动按今日星期展示当天课程,空时显示祝福语
- **待办事项**: 高优(红)、中优(黄)、低优(绿)三色标记

**操作**:
- 点击快捷入口图标 → 跳转对应页面
- 点击"查看全部 ›" → 跳转课表页

### 2. 课程表 (Schedule)

**位置**: 底部 tab "课表"

**功能**:
- 5 天 × 4 节大段网格展示
- 课程按预设颜色分类显示
- 节次显示时间段 (上午 08:00-09:40 等)

**操作**:
- 点击任一课程方块 → 弹出详情 (教师、地点、周次)

### 3. 成绩查询 (Grades)

**位置**: 首页快捷入口 / 我的菜单

**功能**:
- 顶部 GPA、平均分、总学分实时统计
- 学期筛选按钮 (2024-2025-1, 2024-2025-2 等)
- 成绩列表按学期过滤显示
- 分数颜色编码:
  - 90+ 绿色 (优秀)
  - 80-89 蓝色 (良好)
  - 60-79 黄色 (合格)
  - <60 红色 (不及格)

**操作**:
- 点击学期标签 → 切换学期,自动重算 GPA

### 4. 图书馆 (Library)

**位置**: 首页快捷入口 / 我的菜单

**功能**:
- 搜索框: 支持书名/作者关键字模糊匹配
- 筛选标签: 全部 / 借阅中 / 已归还
- 图书卡片显示封面 (Emoji)、标题、作者、出版社、状态

**操作**:
- 在搜索框输入关键字 → 实时过滤
- 点击筛选标签 → 切换显示范围
- 点击图书卡片 → 进入图书详情

### 5. 图书详情 (Book Detail)

**位置**: 图书馆 → 点击某本书

**功能**:
- 显示完整图书信息: 标题、作者、出版社、ISBN、借阅日期、应还日期、内容简介
- 在借状态下显示底部操作按钮

**操作**:
- 点击 "续借" → 弹出确认,确认后应还日期延后 30 天
- 点击 "归还" → 弹出确认,确认后状态变为 "已归还"

### 6. 通知公告 (Notice)

**位置**: 底部 tab "通知"

**功能**:
- 筛选标签: 全部 / 未读 (含数字) / 重要
- 通知列表: 类型标签 + 标题 + 摘要 + 来源 + 日期
- 未读通知左侧蓝色竖条 + 右上角红点

**操作**:
- 点击通知 → 弹出详细内容,自动标记为已读

### 7. 日程 (Calendar)

**位置**: 首页快捷入口 / 我的菜单

**功能**:
- 月历视图,周一到周日 7 列
- 今日日期蓝色圆形高亮
- 选中日期橙色圆形高亮
- 有事件的日期下方红色圆点标记
- 上下方分别显示当日日程和近期日程

**操作**:
- 点击 `‹` / `›` → 切换上一月/下一月
- 点击日期 → 选中并查看当日事件
- 事件按类型染色: 考试(红)/课程(蓝)/活动(黄)/重要(紫)

### 8. 签到 (Check-in)

**位置**: 首页快捷入口 / 我的菜单

**功能**:
- 顶部大数字显示连续签到天数
- 立即签到按钮 (已签到状态时禁用)
- 月度签到日历: 已签到为绿色,今日红框,未来灰色
- 签到奖励: 3 天/7 天/15 天/30 天 阶梯解锁

**操作**:
- 点击 "立即签到" → 完成今日签到,连续天数 +1
- 重复点击 → 提示已签到

### 9. 我的 (Profile)

**位置**: 底部 tab "我的"

**功能**:
- 顶部蓝紫渐变卡片显示头像、姓名、学号、班级
- 数据统计: 签到天数、借阅图书、总 GPA
- 菜单分组:
  - 学习类: 成绩、借阅、日程、签到
  - 服务类: 联系教务、意见反馈、设置

**操作**:
- 点击菜单项 → 跳转或弹出对应信息

### 10. 设置 (Settings)

**位置**: 我的 → 设置

**功能**:
- **外观设置**:
  - 主题模式: 浅色 / 深色 / 自动
  - 字体大小: 小 / 中 / 大
- **通知设置**:
  - 课程提醒开关
  - 考试提醒开关
  - 公告推送开关
- **数据管理**:
  - 清除缓存
  - 重置数据 (恢复初始示例数据)
- **关于**:
  - 版本号
  - 关于校园助手
  - 隐私协议
- **退出登录**

## 四、常用操作流程

### 查询本学期成绩
1. 进入首页 → 点击"成绩" 图标
2. 切换至 "2024-2025-2" 学期
3. 查看 GPA 和各科分数

### 借阅图书续借
1. 进入首页 → 点击 "图书馆"
2. 找到要续借的图书,点击进入详情
3. 点击底部 "续借" 按钮 → 确认

### 完成今日签到
1. 进入首页 → 点击 "签到" 图标
2. 查看连续天数
3. 点击 "立即签到" 完成

## 五、提示与建议

1. **数据持久化**: 所有操作都会保存到本地 `wx.storage`,关闭小程序数据不会丢失
2. **重置数据**: 想要恢复初始示例数据,可在"设置 → 重置数据"中操作
3. **离线使用**: 本应用完全离线工作,不依赖任何后端服务
4. **真机调试**: 建议在微信开发者工具中点击"预览"按钮,扫码后用手机微信打开,体验最佳

## 六、常见问题

**Q: 为什么签到天数没变?**
A: 连续签到必须每日不间断签到,中断后会重置为 1。

**Q: 课表的时间是固定的吗?**
A: 是的,当前版本的时间段固定 (上午 08:00-09:40 等),后续版本将支持自定义。

**Q: 如何删除某条数据?**
A: 当前版本仅支持图书归还操作。后续将增加完整 CRUD 能力。

**Q: 数据存储有限制吗?**
A: 微信小程序单个 Key 上限 1MB,总存储上限 10MB,普通使用不会超限。
