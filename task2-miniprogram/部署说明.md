# 校园助手 - 部署说明

> 本文档详细说明如何在本地及生产环境部署运行校园助手小程序。

## 一、环境要求

### 硬件要求
- 操作系统: Windows 10+ / macOS 10.13+ / Linux (有限支持)
- 内存: 4GB 以上
- 存储: 1GB 可用空间

### 软件要求
- **微信开发者工具**: 1.06.2308 以上版本
- **微信账号**: 用于真机预览扫码
- **基础库**: 2.30.4 及以上

## 二、下载微信开发者工具

### 官方下载地址
[https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 选择对应版本
| 系统 | 下载链接 |
|------|---------|
| Windows 64 | 下载 Windows 64 位稳定版 |
| Windows 32 | 下载 Windows 32 位稳定版 |
| macOS | 下载 macOS 稳定版 |

### 安装步骤
1. 下载完成后双击安装包
2. 按照向导完成安装 (Windows 选择安装路径; macOS 拖入 Applications 文件夹)
3. 首次启动需扫码登录微信开发者账号

## 三、获取 AppID

### 方案一: 个人小程序 (推荐学习使用)
1. 访问 [微信公众平台](https://mp.weixin.qq.com)
2. 点击 "注册" → 选择 "小程序"
3. 填写邮箱 (未注册过公众号) 完成账号注册
4. 完成主体信息认证 (个人即可)
5. 登录后台 → "开发 → 开发管理 → 开发设置" → 查看 AppID

### 方案二: 使用测试号 (最快)
1. 在微信开发者工具导入项目时,选择 "测试号"
2. 工具会自动分配临时 AppID
3. 适合学习和教学演示,**但不能上传发布**

## 四、导入项目步骤

### Step 1: 启动微信开发者工具
- Windows: 开始菜单 → 微信开发者工具
- macOS: Launchpad → 微信开发者工具

### Step 2: 导入项目
1. 进入工具主界面后,点击左侧 "小程序" 标签
2. 点击 "+ 导入项目" 按钮
3. 填写表单:
   - **项目目录**: 选择 `task2-miniprogram` 文件夹的绝对路径
   - **AppID**: 填入您的 AppID,或勾选 "测试号"
   - **项目名称**: 校园助手 (可自定义)
   - **后端服务**: 不使用云服务
4. 点击 "导入" 按钮

### Step 3: 等待初始化
- 工具会自动安装依赖、解析项目结构
- 首次导入可能需要 30 秒左右

## 五、编译与运行

### 5.1 编译项目
- 点击工具栏 "编译" 按钮 (或快捷键 `Ctrl+B` / `Cmd+B`)
- 等待编译完成,模拟器自动显示首页

### 5.2 调试模式
- 工具底部分为: **模拟器** / **编辑器** / **调试器** 三栏
- **模拟器**: 可切换不同机型 (iPhone X, 微信 8.0 等)
- **调试器**: 类似浏览器 DevTools,可查看 Console、Sources、Network 等
- **AppData**: 实时查看页面数据状态
- **Storage**: 查看本地存储数据

### 5.3 切换页面
- 模拟器中点击 tabBar 切换页面
- 调试器 → AppData 可手动修改数据测试

### 5.4 模拟功能
- **网络条件**: 工具栏 → 网络可模拟弱网/离线
- **机型**: 模拟器顶部下拉切换不同机型测试兼容性

## 六、真机预览

### 6.1 生成预览
1. 点击工具栏 "预览" 按钮
2. 工具会构建小程序并生成二维码

### 6.2 扫码预览
1. 打开手机微信
2. 扫描工具显示的二维码
3. 微信将自动打开你的小程序,可完整体验所有功能

### 6.3 真机调试 (高级)
- 点击工具栏 "真机调试" 按钮
- 扫码后可在桌面工具实时查看手机端的 Console 和 Network

## 七、上传与发布

> 仅适用于已实名认证的正式 AppID,测试号无法上传

### 7.1 上传代码
1. 点击工具栏 "上传" 按钮
2. 填写版本号 (如 `1.0.0`) 和项目备注
3. 点击 "上传" 完成

### 7.2 提交审核
1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入 "管理 → 版本管理"
3. 在 "开发版本" 列表找到刚上传的版本
4. 点击 "提交审核"
5. 填写审核信息:
   - 小程序名称、简介、类目
   - 截图 (建议 3-5 张)
   - 联系方式
6. 提交后等待官方审核 (通常 1-3 个工作日)

### 7.3 发布上线
1. 审核通过后,在 "审核版本" 中点击 "发布"
2. 选择 "全量发布"
3. 发布完成后,用户可在微信中搜索小程序名称使用

## 九、常见问题排查

### Q1: 导入项目报错 "AppID 不合法"
**解决**: 检查 AppID 是否复制完整 (18 位字符),或选择 "测试号"。

### Q2: 编译报错 "找不到 app.json"
**解决**: 检查项目根目录是否包含 `app.json`,确认导入时选择的是 `task2-miniprogram` 文件夹,而不是其父目录。

### Q3: tabBar 图标显示不出来
**解决**: 检查 `images/` 目录下是否存在 8 个 PNG 文件 (4 个未选中 + 4 个选中态)。若缺失,可从仓库重新拉取,或参考 `images/README.md` 自行制作。

### Q4: 真机预览扫码后白屏
**解决**:
- 确认编译时没有报错
- 工具设置 → "本地设置" → 勾选 "不校验合法域名"
- 删除小程序缓存,重新扫码

### Q5: 网络请求被拦截
**解决**: 本项目纯本地,无外部网络请求,无需配置服务器域名。如出现该问题,在工具设置中关闭 "URL 校验"。

### Q6: 我的图标不显示头像
**解决**: 头像使用了 `dicebear.com` 外部图片服务。如外网受限可在 `app.js` 中将 `avatar` 改为本地图片 (如 `/images/avatar-default.png`)。

### Q7: 模拟器卡顿
**解决**: 降低模拟器分辨率,或关闭 "真机调试" 等高耗能选项。

## 十、生产环境优化建议

1. **图标资源**: 替换 `images/` 中的占位 PNG 为正式 81×81 透明图标
2. **真实数据**: 接入学校教务系统 API 替代 mock 数据 (需服务器域名备案)
3. **用户登录**: 接入微信 `wx.login` + 学号绑定
4. **云开发**: 使用微信云开发集成数据库、云函数
5. **性能监控**: 在小程序管理后台开启监控告警
6. **版本管理**: 使用 git 管理代码,按 SemVer 规范打 tag
